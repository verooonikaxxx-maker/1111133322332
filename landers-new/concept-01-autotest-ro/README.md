## Чего в ленде нет намеренно

Ни одного выдуманного эксперта, отзыва, пациента, фотографии «до/после»,
клинического процента, названия несуществующего метода или технологии.
Ни одного псевдосчётчика вида `19 974 / 20 000` и `33/1000`.

Убедительность держится на трёх механизмах, которым выдумка не нужна:
самодиагностика, объяснение физиологии (аваскулярность хряща, питание диффузией)
и честное перечисление ограничений продукта.

## Технический слой

Все дефекты старой серии исправлены, ни один не перенесён:

| | Старая серия | Здесь |
|---|---|---|
| Фильтр имени | `[^a-zA-Zа-яА-ЯёЁії ]` — режет диакритику | `\p{L}\p{M}` — `Ștefan Ionuț-Mărgărit` проходит целиком |
| Телефон | `[0-9]{6,}`, вырезает `+` | минимум 10 цифр (RO), `+` сохраняется |
| jQuery | cdnjs, в `<head>`, без `defer` | **нет вообще** — ванильный JS, 7 КБ |
| Картинки | 224 ссылки на `static.joxi.pro` | **нет внешних ресурсов**, схема — инлайновый SVG |
| `lang` | `es-AR` на румынском ленде | `ro-RO` |
| `robots` | у VSL отсутствовал | `noindex, nofollow` |
| lazy | все картинки, включая первый экран | только то, что ниже сгиба |
| Классы | `pachinoform`, `obertk512`, `number-me` — отпечаток серии | своя схема имён |
| Дубли `id` | `oneform` объявлен дважды | нет |

Форма сохраняет рабочий контракт: `action="/order.php"`, скрытые `fbpx`, `utm_code`,
`cid`, `sid`, `hash`, `country`, макросы Keitaro `{fbpx}` `{subid}` `{campaign_id}` `{hash}`.
