# Лендинг TR — недержание, имам (CY-Relief)

Видео: интервью с имамом Нуреттином Караагач Ходжа (озвучка по
`scenario-imam-TR-ozvuchka.md`). Файл кладётся как `TR606.mp4` —
имя в разметке оставлено прежним, чтобы ничего больше не править.

В папке только `index.html`. `css/`, `js/`, `images/` берутся из
исходной сборки без изменений, плюс в `js/` нужен
`jquery-3.6.0.min.js` для локального фолбэка.

## Что адаптировано

- Заголовок: профессор-уролог заменён на ходжу. Он не «открыл», а
  «рассказал о дермане, о котором доктора говорить не любят» —
  имам не выступает в роли врача.
- Три отзыва получили турецкий триггер: абдест, намаз, пятничная
  мечеть, «как говорил наш ходжа». Имена, фото, лайки, даты не тронуты.
- Язык отзывов приведён к разговорному: `mucizevi ürün` → `Allah razı
  olsun`, `sihirli bir şekilde` → `bir anda`, `stres` → `telaş`.

## Что починено

- `lang="es-AR"` → `lang="tr"`.
- Плейсхолдеры формы были португальские (`Nome`, `Número de telefone`)
  → `Adınız`, `Telefon numaranız`.
- Два элемента с `id="oneform"`: пустой `<span>` стоял перед видео, и
  скролл по CTA уезжал выше плеера. Span убран, якорь — `<div>` перед
  формой.
- Телефон: `pattern="[0-9]{6,}"` → `[0-9]{10,11}` под турецкий номер,
  добавлен `inputmode="numeric"`.
- Скрипт вешал `loading="lazy"` на все картинки, затирая `eager` в
  разметке. Скрипт убран, `loading` расставлен явно: товар и логотипы
  каналов `eager`, семь аватаров отзывов `lazy`.
- `$('a').on('touchend, click')` → `'touchend click'`. jQuery делит по
  пробелам, поэтому `touchend,` не срабатывал никогда.
- jQuery c cdnjs получил локальный фолбэк: при недоступности CDN
  форма и скролл раньше молча умирали.
- Убраны два пустых `<style></style>`.

## Что не тронуто

`sid=6395`, `{_box:G8r3zfLP}`, `action="/order.php"`, все скрытые поля,
`start=120 / duration=600`, редирект RU-трафика, цены, таймер, счётчик
остатка, `video.js`.
