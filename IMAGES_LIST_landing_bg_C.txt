ЕСЛИ КАКОГО-ТО ФАЙЛА НЕТ
───────────────────────────────────────────────────────────────────────
Ленд не сломается — просто на его месте будет «broken image» иконка.
Порядок приоритета (что положить в первую очередь, если фото мало):

  1. images/hero.jpg          ← без него ленд визуально мёртвый
  2. images/product.png       ← без банки не понятно что покупать
  3. images/doctor.jpg        ← без врача теряется траст
  4. images/patient.jpg       ← без пациентки теряется кейс
  5. images/comments/1-10.jpg ← можно и стоковые/AI, но чтобы БЫЛИ
  6. images/headerm.png       ← без него сверху останется пустое место
  7. images/author.jpg        ← самое некритичное

───────────────────────────────────────────────────────────────────────
ФОРМАТ, ЕСЛИ БУДЕТ ЛЕТЬ ЧЕРЕЗ FB
───────────────────────────────────────────────────────────────────────
Все фото — обычные JPG 60-80% quality, без ватермарков, без текста
поверх (FB режет). Hero — можно без людей (растение), чтобы не
триггерить «до/после» модерацию. Doctor/patient — реальные люди,
не AI-морды с искажёнными руками/зубами (модерация ловит).
