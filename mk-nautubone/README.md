# Nautubone — advertorial за Северна Македонија (MK)

Адаптација на германскиот Funnelish advertorial („Hamburger Radiologin…“) за пазарот
во Северна Македонија, со офертата **Nautubone гел за зглобови**.

## Што е сменето наспроти оригиналот

| | Оригинал (DE) | Оваа верзија (MK) |
|---|---|---|
| Јазик | германски | македонски (`lang="mk"`) |
| Производ | ArthroCare+ капсули | **Nautubone гел** (трансдермален) |
| Цена | — | **4800 → 2400 MKD** (−50 %) |
| Автор | Dr. Anja Brenner, Хамбург | д-р Ана Стојаноска, радиолог, Скопје |
| Бренд на медиумот | Heilkompass Magazin | Здрав Компас |
| Конверзија | Funnelish CTA (`#next-step`) | **формулар за колл-центар** (`/order.php`) |
| Гаранција | 100 дена враќање пари | плаќање при достава (COD) |

Клучна содржинска адаптација: бидејќи офертата е **гел, а не капсули**, механизмот е
пренасочен — хрскавицата нема крвни садови, па оралниот пат разредува сè; трансдермалниот
пат носи директно до зглобот. Тоа истовремено објаснува зошто на читателот претходно
му „не помогнале таблетите“.

## Форма за нарачка

Земена е 1:1 од постоечкиот MK лендинг:

```
action="/order.php"  method="post"
sid      = 2694
country  = MK
макроа   : {fbpx} {subid} {campaign_id} {hash}
трекер   : {_box:2sHZz2rc}   (на дното на страницата)
```

Сите CTA-копчиња и линкови скролаат до `#oneform` (jQuery handler, како во оригиналниот
MK лендинг). Ако jQuery не се вчита, анкерите работат нативно.

## Пред пуштање — што да се замени

1. **Слики на производот** — сега стојат сликите од стариот фунел (Shopify CDN).
   Заменете ги со фотографии на Nautubone, идеално локално во `images/`.
2. **Портрет на авторот** и МР-снимките — исто, преместете ги на сопствен хостинг
   наместо туѓ CDN.
3. **Броевите за скарсити** (`33 /1000`, `Nº 19 974 / 20 000`) се статични —
   поврзете ги со вашата скрипта ако користите динамични бројачи.
4. **Правни линкови** во подножјето (Приватност / Услови / Контакт) сега скролаат до
   формуларот — заменете со вистински URL-ови ако тоа го бара мрежата.
