# Именование

- Транзитка: `landings/<geo>_<vertical>_<slug>/` — например `de_nutra_slim01`.
- Партия креативов: `creatives/incoming/<YYYY-MM-DD>_<источник>/` — например `2026-09-04_adheart`.
- Вариант креатива: `<landing-id>__<angle>__v<N>` — например `de_nutra_slim01__pain-morning__v3`.

Гео — ISO-2 в нижнем регистре. Вертикаль — одно слово: `nutra`, `gambling`,
`betting`, `crypto`, `dating`, `ecom`, `apps`, `finance`.
