# Рабочий процесс: транзитки + уникализация креативов

## 1. Структура репозитория

```
landings/                     # транзитки (прелендинги/лендинги)
  <geo>_<vertical>_<slug>/
    src/                      # оригинал как есть (index.html, css, js, img)
    meta.json                 # паспорт транзитки (см. ниже)
    NOTES.md                  # разбор: оффер, боли, УТП, структура, CTA
creatives/
  incoming/<batch-id>/        # то, что прислано (спай-выгрузки, как есть)
  output/<batch-id>/          # уникализированные варианты + маппинг на транзитки
docs/
  WORKFLOW.md                 # этот файл
  NAMING.md                   # правила именования
Claude_Skill_-_Performance_Copywriting/   # скилл по копирайтингу (используется при уникализации)
```

## 2. Паспорт транзитки — `meta.json`

```json
{
  "id": "de_nutra_slim01",
  "geo": ["DE"],
  "lang": "de",
  "vertical": "nutra",
  "offer": "название оффера",
  "type": "quiz | article | store | prelander",
  "format": "html | html+video",
  "cta": "текст кнопки",
  "promise": "главное обещание страницы",
  "pains": [],
  "proof": ["отзывы", "цифры", "до/после"],
  "tone": "expert | ugc | news",
  "traffic_source": ["facebook", "tiktok", "google"],
  "tracker_macros": ["{clickid}", "{sub1}"],
  "status": "active"
}
```

## 3. Цикл работы с креативами

1. Партия креативов кладётся в `creatives/incoming/<batch-id>/` в исходном виде.
2. Разбор: оффер, гео, язык, угол (angle), хук, боль, оффер, CTA, формат.
3. Матчинг: какой транзитке из `landings/` соответствует креатив
   (гео + язык + вертикаль + обещание + тон).
4. Уникализация: новый текст под то же обещание, но своей структурой,
   лексикой и хуком; сохраняется смысловая связка «креатив → транзитка».
5. Результат в `creatives/output/<batch-id>/`:
   - `variants.md` — варианты текстов
   - `mapping.csv` — креатив → транзитка → УТП → CTA
   - `brief.md` — что менять в визуале/сценарии видео

## 4. Правило связки

Обещание креатива = обещание первого экрана транзитки.
Если транзитка обещает X, а креатив обещает Y — связка не собирается,
это фиксируется в `mapping.csv` со статусом `mismatch`.
