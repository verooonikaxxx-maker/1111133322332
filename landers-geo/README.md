## Требует решения перед заливом

1. **sid** под SK, RS, LV, LT — суставных sid под эти ГЕО в наших лендах нет.
2. **Цены** с пометкой ⚠️ взяты по точке серии или из ленда под другой оффер.
3. **Статистика из Польши** — `125 000 новых случаев`, `23 000`, `19 000 человек`
   перенесены из исходника без пересчёта. Для малых стран нереальны.
4. **Фраза про имя продукта** — «дал ему это имя в честь отца». В CR и SK
   развязана, в остальных оставлена как в исходнике.

## Сборка

В папках только `index.html`. Нужны `css/`, `images/` и `js/dtime.js`
из исходной сборки — без `dtime.js` не отрисуются даты.

Во всех, кроме CR и SK, дата в блоке обновления живая: штатный
`<span class="startdate">` с `dtime_nums(0)`.
