# landers-sustavy

Сюда `download-landers.sh` складывает выгруженные транзитки на суставы —
по папке на оффер: `<offer_id>_<ГЕО>_<краткое имя>/` с `index.html`,
`images/` и `js/` внутри.

## Как выгрузить

```bash
bash download-landers.sh ./landers-sustavy
```

Нужен `wget` (предпочтительно) или `curl`. На маке: `brew install wget`.

## Почему папка пустая

Скрипт запускался в облачной сессии Claude Code — там исходящий трафик
ограничен allow-list'ом, и `pro1.trk.dev` в него не входит: прокси отдаёт
403 на CONNECT ещё до соединения с сервером трекера. Все 7 транзиток
вернулись пустыми. Скрипт при этом рабочий (синтаксис и логика проверены) —
запускайте его локально или с машины, у которой есть доступ к `pro1.trk.dev`.

Список путей к лендерам — в `sustavy-transitki.md`, раздел 3.
